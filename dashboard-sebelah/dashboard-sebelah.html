Tentang data dan model

Sumber data, cara membaca, dan versi model

Sumber: dashboard dan laporan project "TRAIN ANOMALY DETECTION" (RUP dan realisasi APBD provinsi 2025, INAPROC). Lingkup project itu: paket penyedia, pagu minimal Rp1.000 (bukan Rp1 juta seperti project ini). Jalur pelaksanaan: paket dengan realisasi selesai (Serah Terima), dibersihkan dari rasio realisasi/pagu yang tidak masuk akal.

Model project sebelah: Isolation Forest + LOF + Autoencoder, skor tiap model diubah ke persentil lalu dirata-rata, diulang 5 seed. Paket "tidak lazim" = 5% skor tertinggi nasional. Fitur perencanaan (6): posisi pagu di antara paket sejenis, posisi pagu di satker, porsi pagu satker yang diserap, kebulatan pagu, pagu kembar di satker, porsi non-kompetitif satker. Pelaksanaan menambah 3: posisi realisasi/pagu, jangkauan penyedia, dan nilai dibanding kebiasaan penyedia.

Red flag: 12 (P1–P6 perencanaan, E1–E6 pelaksanaan). Empat di antaranya (P2, P3, E1, E2) bocor karena dihitung dari angka yang sama dengan fitur, jadi hanya red flag bersih yang dipakai untuk Precision@K.

Yang berbeda dari dashboard project ini: hanya 200 paket teratas per jalur yang punya rincian, skor IF/LOF/AE per paket dan daftar paket pembanding tidak tersedia, alasan poin diambil dari kalimat project sebelah, dan peta memakai interval Wilson 95% (▲/▼).
